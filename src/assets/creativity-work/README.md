# Creativity work pictures

Drop images here (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`). They show up automatically in
**Social impact › Creativity work** — no code change needed. Restart `npm run dev` if a new file doesn't appear.

- **Order:** alphabetical by file name, so number them: `01-lena.jpg`, `02-marco.jpg`, …
- **Name under the picture:** taken from the file name, without the number and extension.
  `01-lena.jpg` → «Lena», `03-anouk-and-tom.png` → «Anouk And Tom».
- **Size:** square or portrait works best (tiles are about 100 × 120 px, shown cropped). Keep files under ~500 KB.

Photos people take with the camera in the app are shown **before** these.
Empty tiles only appear when there are fewer than 3 pictures in total.
