# Artothek on Instagram pictures

Drop images here (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`). The **first 3** (alphabetical by file name)
show in **Social impact › Artothek on Instagram** — no code change needed. Restart `npm run dev` if a new file doesn't appear.

- **Order:** number them to choose: `01-living-room.jpg`, `02-hallway.jpg`, `03-kitchen.jpg`.
- **Size:** square works best (tiles are about 90 × 96 px, shown cropped). Keep files under ~500 KB.

Until there are 3 pictures here, the remaining tiles stay as plain placeholders.
