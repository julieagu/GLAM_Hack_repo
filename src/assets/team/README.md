# Team photos

Drop one photo per person here (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`). They show up automatically
on the **About** page — no code change needed. Restart `npm run dev` if a new file doesn't appear.

- **File name = first name** (lower case is fine): `christine.jpg`, `juliane.jpg`, `lara.jpg`, `julie.jpg`.
- **Size:** square works best (shown as a 1:1 crop). Keep files under ~500 KB.

Until a photo is here, the About page shows a pink placeholder with the person's initial.
Names, roles and descriptions are in `src/data/team.ts`.
